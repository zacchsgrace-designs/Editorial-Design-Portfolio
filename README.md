# Editorial Design Portfolio

One-page portfolio website for Grace Zacchaeus, editorial designer, book cover designer, and book formatter.

## Files
- `index.html`: the whole website (HTML, CSS, and a little JavaScript). Colors are set at the top, in the `:root{}` block.
- `*.jpg`: cover designs, mockups, and portraits used on the page.

## Preview
Open `index.html` in a browser. Keep it in the same folder as the images.
